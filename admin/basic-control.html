Azure Translate API Configuration

Instruction

To use the Microsoft Azure Translator API, follow these steps:

  1. Subscription Key
    Log in to Azure → Go to Translator Resource → Under “Keys and Endpoint” copy Key1 or Key2.
  2. Endpoint (URL)
    From the same section, copy the URL under “Endpoint”.
  3. Subscription Region
    Region is found under “Location”.

You now have:

  • Subscription Key
  • Endpoint URL
  • Subscription Region
